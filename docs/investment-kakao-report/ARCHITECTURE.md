# 인베스톡(InvestTalk) 아키텍처

카카오톡 메시지의 링크를 눌러 투자 뉴스, 기업 정보(공시·재무·영업), 경제 지표 리포트를
바로 열람할 수 있는 서비스의 시스템 프레임워크.

> 본 문서는 현재 저장소(GlobalMatch, 국제 매칭 앱)와는 별개의 신규 서비스 기획으로,
> 요청에 따라 프레임워크 설계와 다이어그램만을 정리한 설계 문서입니다.
> 시각화된 버전은 아래 Artifact 링크를 참고하세요.

## 1. 서비스 개요

- **한 줄 정의**: 카카오톡 알림톡/친구톡으로 투자 인사이트를 요약해 보내고,
  링크를 클릭하면 웹 리포트 뷰어에서 상세 리포트(뉴스 원문 요약, 기업 재무/공시,
  경제 지표 차트)를 확인하는 서비스.
- **핵심 가치**: 카카오톡을 채널로 써서 앱 설치 없이(No-install) 접근 가능,
  개별 종목/산업/거시지표를 구독 기반으로 받아볼 수 있음.

## 2. 핵심 사용자 흐름

1. 사용자가 카카오톡 채널을 추가하고 관심 기업/산업/지표를 구독 설정
2. 백엔드가 뉴스·공시·지표를 수집·가공해 리포트를 생성
3. 발송 스케줄러가 구독 규칙에 맞는 사용자에게 알림톡(요약 + 링크) 발송
4. 사용자가 카카오톡에서 링크 클릭 → 웹 리포트 뷰어로 이동 → 상세 리포트 열람
5. 열람 이력·즐겨찾기가 다시 구독/추천 로직에 반영 (피드백 루프)

## 3. 시스템 구성 (레이어별)

### 3.1 데이터 수집 레이어
- **기업 공시/재무**: OpenDART(전자공시시스템) API — 재무제표, 공시, 임원/최대주주,
  배당·자본변동 정보
- **뉴스**: 언론사 RSS, 뉴스 API(네이버 뉴스 등), 크롤러
- **거시/경제 지표**: 한국은행 ECOS, 통계청 KOSIS(국내), FRED(해외)
- **수집 방식**: 주기적 배치(cron/워커) + 공시·속보성 데이터는 폴링 또는 웹훅

### 3.2 데이터 처리 · AI 분석 레이어
- 원시 데이터 정제/정규화 (기업 코드 매핑, 중복 제거)
- LLM 기반 요약·리포트 초안 생성 (뉴스 요약, 공시 해설, 지표 코멘터리)
- 감성/이슈 태깅으로 리포트 우선순위·알림 트리거 결정

### 3.3 리포트 생성 레이어
- 템플릿 기반 리포트 조립 (데일리 브리핑 / 기업 리포트 / 산업 리포트 / 지표 리포트)
- 리포트별 고유 ID + 단축 링크 발급, 버전 관리

### 3.4 카카오톡 발송 레이어
- 카카오 비즈니스 메시지(알림톡·친구톡)로 요약 + "자세히 보기" 버튼 발송
- 카카오싱크로 사용자 인증 연동, 구독 규칙 기반 발송 스케줄러
- 발송 성공/실패, 클릭률(CTR) 로그 적재

### 3.5 웹 리포트 뷰어 (프론트엔드)
- 모바일 최적화 웹앱(PWA), 딥링크로 특정 리포트 즉시 진입
- 비로그인 상태에서도 토큰 기반으로 열람 가능, 상세 기능은 로그인 유도
- 기업 검색, 관심기업 등록, 지표 차트 시각화

### 3.6 사용자 · 구독 관리
- 카카오 로그인 기반 회원, 관심 기업/산업/키워드 구독 관리
- 유료 프리미엄 리포트(선택), 알림 빈도 설정

### 3.7 관리자 · 분석 대시보드
- 리포트 발행 관리, 발송 통계/CTR, 데이터 소스 상태 모니터링

## 4. 기술 스택 제안

| 레이어 | 기술 |
|---|---|
| 프론트엔드(리포트 뷰어) | Next.js 15 + TypeScript + Tailwind CSS (PWA) |
| 백엔드 API | Next.js API Routes 또는 NestJS |
| 데이터베이스 | PostgreSQL(Supabase) + Redis 캐시 |
| 오브젝트 스토리지 | Supabase Storage / S3 (리포트 PDF, 이미지) |
| 외부 데이터 | OpenDART API, 뉴스 API/RSS, 한국은행 ECOS, KOSIS, FRED |
| AI 요약/리포트 생성 | Claude API |
| 카카오 연동 | 카카오 비즈니스 메시지(알림톡/친구톡), 카카오싱크, 카카오 채널 |
| 스케줄러/워커 | Cron 워커 (Railway/AWS EventBridge + Lambda) |
| 인증 | Supabase Auth + 카카오 OAuth |
| 결제(프리미엄, 선택) | Stripe 또는 카카오페이 |
| 모니터링 | Sentry, 발송 통계 로그 |
| 배포 | Vercel(프론트), Railway/AWS(백엔드·워커) |

## 5. 데이터베이스 스키마 초안

- `users` — 사용자, 카카오 연동 정보
- `companies` — 기업 마스터(종목코드, 산업분류)
- `disclosures` — OpenDART 공시 원문/요약
- `news_articles` — 뉴스 원문/요약/감성 태그
- `economic_indicators` — 거시 지표 시계열
- `reports` — 생성된 리포트(타입, 대상, 본문, 단축 링크)
- `report_deliveries` — 발송 이력(사용자, 리포트, 채널, 클릭 여부)
- `user_watchlists` — 사용자별 관심 기업/산업/키워드 구독
- `notification_logs` — 알림톡 발송 성공/실패 로그

## 6. 시퀀스: 메시지 발송 → 리포트 열람

```
스케줄러 → 리포트 생성기 : 발송 대상 리포트 조회
스케줄러 → 카카오 비즈니스 API : 알림톡 발송(요약 + 링크)
카카오 → 사용자 : 카카오톡 메시지 수신
사용자 → 웹 리포트 뷰어 : 링크 클릭(토큰 포함 URL)
웹 리포트 뷰어 → 백엔드 API : 토큰 검증 + 리포트 조회
백엔드 API → DB : 리포트/기업/지표 데이터 조회
웹 리포트 뷰어 → 사용자 : 리포트 렌더링(요약, 차트, 원문 링크)
사용자 → 백엔드 API : 열람/즐겨찾기 기록(개인화 피드백)
```

## 7. 단계별 로드맵

- **Phase 1 (MVP)**: 기업 검색 + 공시 요약 리포트, 수동 트리거 알림톡 발송,
  토큰 기반 웹 리포트 뷰어
- **Phase 2**: 데일리 브리핑 자동 발송, 관심기업 구독, 카카오싱크 로그인
- **Phase 3**: AI 개인화 추천, 경제지표 대시보드, 산업 리포트, 프리미엄 구독
- **Phase 4**: 실시간 속보 알림, 행동 기반 큐레이션, 관리자 분석 고도화

## 8. 고려사항

- **규제**: 투자 자문/권유로 오인되지 않도록 정보 제공 목적임을 명시, 금융 콘텐츠
  관련 법규(자본시장법 등) 검토 필요
- **카카오 정책**: 알림톡은 정보성 메시지만 허용(광고성 메시지는 친구톡/광고 심사 필요),
  템플릿 사전 승인 필요
- **데이터 라이선스**: 뉴스/시세 데이터 재배포 시 API/저작권 라이선스 확인
- **보안**: 리포트 열람 토큰 만료 처리, 사용자 개인정보(구독 정보) 보호
