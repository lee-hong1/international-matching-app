# 마켓브리프 — 시스템 아키텍처

카카오톡으로 받은 링크 하나로, 그 시점에 갱신된 투자 리포트(뉴스·기업 공시·재무·경제지표·시세)를 모바일 웹에서 바로 확인하는 서비스의 프레임워크 설계입니다.

시각 자료(다이어그램 포함 전체 문서): [Artifact — 마켓브리프](https://claude.ai/artifact/24dPLUdnumrXQsBT8Wbggz)

## 사용자 흐름

1. **카카오톡 수신** — 정기 브리핑 또는 관심 기업 속보를 알림톡·친구톡으로 수신
2. **링크 탭** — 메시지 속 리포트 링크를 눌러 별도 앱 없이 바로 접속
3. **리포트 열람** — 뉴스·공시·재무·경제지표가 한 페이지로 정리된 모바일 리포트 확인

## 시스템 계층

| 계층 | 역할 | 주요 기술 |
|---|---|---|
| 수집 · ETL | 외부 소스 주기 수집, 검증·정규화 | Node.js, Cron/Queue Worker, Zod |
| 코어 데이터 스토어 | 기업·리포트·구독 데이터 저장 및 캐시 | PostgreSQL(Supabase), Redis |
| 리포트 생성 엔진 | 템플릿 렌더링 + LLM 요약/인사이트 | Claude API |
| 발송 · 카카오 연동 | 정기/이벤트 트리거 기반 리포트 링크 발송 | 알림톡, 친구톡, 카카오 로그인 |
| 리포트 웹 뷰어 | 링크 접속 시 모바일 최적화 리포트 렌더링 | Next.js 15 (SSR), Tailwind CSS |
| 트래킹 · 분석 | 열람/클릭 데이터 수집 → 코어 스토어로 피드백 | 이벤트 로그, 대시보드 |

## 데이터 흐름 (두 가지 트리거)

- **정기 브리핑**: 스케줄 트리거 → 구독자 매칭 → 리포트 렌더링 → 알림톡 발송 → 열람 로그 수집
- **이벤트 속보**: 공시/뉴스 감지 → 중요도 판정 → 속보 리포트 생성 → 친구톡 발송 → 온디맨드 갱신

## 카카오 연동 지점

| 연동 지점 | 기능 | 목적 |
|---|---|---|
| 알림톡 | 승인된 템플릿 기반 정보성 메시지 | 정기 브리핑, 구독 안내 |
| 친구톡 | 자유 형식 메시지 | 이벤트 속보, 프로모션 안내 |
| 카카오 로그인 | OAuth 간편 인증 | 마찰 없는 구독자 식별·개인화 |
| 카카오톡 공유하기 | 리포트 페이지 지인 전달 | 자연 유입 확산 |

리포트 링크 형식 예: `marketbrief.app/r/{reportId}?src=alimtalk&uid={hash}` — 리포트 단위 열람 추적과 채널별 성과 분리를 지원합니다.

## 리포트 페이지 구성

1. 뉴스·속보 요약
2. 기업 개요·공시
3. 재무·영업 지표
4. 경제지표·흐름
5. AI 인사이트 요약

## 데이터 소스 매핑

| 카테고리 | 소스 / API |
|---|---|
| 뉴스·속보 | 뉴스 API, 언론사 RSS |
| 기업 공시 | DART OpenAPI |
| 재무·영업 정보 | DART 재무제표, 사업보고서 |
| 경제지표 | 한국은행 ECOS, 통계청 KOSIS |
| 시세·지수 | KRX, 증권사 시세 API |

## 로드맵

- **Phase 1 — MVP**: 관심종목 등록, 일 1회 정기 리포트, 알림톡 발송, 모바일 리포트 뷰어
- **Phase 2 — 이벤트 속보·개인화**: 공시/뉴스 이벤트 즉시 발송, 카카오 로그인, 지표 커스터마이징
- **Phase 3 — 고도화·확장**: 심층 분석 리포트, 포트폴리오 단위 브리핑, 공유 바이럴 루프, 유료 구독
