# Project rules

## Design kickoff (mandatory)
Before writing any UI, frontend, or visual-design code - for a new project, page, feature or redesign - invoke the `design-kickoff` skill (`.claude/skills/design-kickoff/SKILL.md`). It runs the reference-site catalog, shows the user example design styles with links, recommends one, gets their choice, and records it in `docs/design/DESIGN_DIRECTION.md`. Skip only when that file already exists and the user has not asked to revisit the look.
